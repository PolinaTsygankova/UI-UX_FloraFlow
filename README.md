## 📌 Проєкт

**FloraFlow** — навчальний вебзастосунок, розроблений у межах практичної роботи №1 з дисципліни «UI/UX дизайн».
Мета проєкту — створити естетичний, мінімалістичний та мотивуючий інтерфейс для студентів і людей, які борються з прокрастинацією чи втратою концентрації під час тривалої роботи.

Застосунок перетворює рутинні інтервали навчання на гру: кожна завершена 25-хвилинна сесія фокусу (за методом «Помідоро») «поливає» віртуальну рослину. Протягом циклу із кількох сесій рослина еволюціонує від насіння до повноцінної квітки.

---

## 🎨 Візуальний стиль та брендинг

- **Концепція логотипа:** Комбінований знак, що поєднує циферблат годинника (таймер, контроль часу) та тюльпан (природа, ріст, результат).
- **Колірна палітра (WCAG 2.1 перевірено):**
   - 🌿 **Шавлієвий зелений** (`#6B847A`) — основний колір для графіки та рамок.
   - 🍑 **Персиковий акцент** (`#E1B49D`) — пелюстки та індикатори прогресу.
   - 🪵 **Темно-лісовий** (`#2A3B34`) — контрастний текст (коефіцієнт контрастності 10.50:1).
   - 🌾 **Кремовий фон** (`#F5F1E8`).

## 🚀 Основний функціонал

1. **Інтерактивна заставка (Splash Screen):** Плавна анімація з індикатором завантаження та асинхронним переходом (`async/await`) без блокування потоку.
2. **Таймер фокусу (Pomodoro):** Повноцінний таймер на 25 хвилин із кнопками «Старт/Пауза», «Скинути» (з повним обнуленням сесій і раундів) та демо-режимом для швидкої перевірки.
3. **Гейміфікація саду:** Динамічна генерація векторних SVG-стадій росту рослини залежно від кількості завершених сесій.
4. **Адаптивні теми:** Підтримка світлої та темної тем інтерфейсу з ручним перемиканням (кнопка у шапці), збереженням вибору в `localStorage` та автовизначенням системних налаштувань.
5. **Блок «Про застосунок»:** Інформація про автора, версію та стек технологій.
