# UI-UX_FloraFlow
# lab-01: логотип та екран «Про застосунок»

Навчальний веб-застосунок до практичної роботи №1 (UI/UX дизайн): екран-заставка з логотипом, після неї – головний екран із таймером фокусу, віртуальною рослиною та блоком «Про застосунок».

**FloraFlow – Deep Focus** – гейміфікований таймер фокусу та продуктивності з елементами віртуального садівництва для студентів і тих, хто швидко втрачає мотивацію під час монотонної роботи. Кожна завершена сесія фокусу (25 хвилин) поливає цифрову рослину, яка зростає від паростка до квітки.

## Склад
- `index.html` – розмітка екранів (заставка, головний екран)
- `style.css` – стилі, світла й темна теми
- `app.js` – таймер фокусу, стадії росту рослини й неблокуючий перехід заставка → головний екран (async/await)
- `logo.png` – основний логотип (растр 744×766), `wordmark.png` – назва для шапки, `icon.png` – іконка та favicon (512×512)

## Запуск
Збирання не потрібне.
1. Відкрийте `index.html` у браузері (подвійний клік), або
2. запустіть локальний сервер у цій теці: `python -m http.server 8000` і відкрийте http://localhost:8000

Кнопка «Завершити (демо)» одразу зараховує сесію, щоб побачити ріст рослини без очікування 25 хвилин.
